# Crosby-style agent redline test, v0.52

Each question is a redline proposed by an AI agent (Claude Sonnet) that did not see the attorney's markup. The label is
yes when the redline is exactly the attorney's markup and no otherwise. This is Crosby's training label; Crosby's test
is a private set reviewed by attorneys. The numbers are not comparable.

Source: [ContractBench](https://huggingface.co/datasets/micro1-inc/ContractBench), CC BY 4.0.
